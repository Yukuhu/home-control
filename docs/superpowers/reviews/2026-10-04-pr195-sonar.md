failed on 8.9% new-code coverage and a C security rating. Python tests ran, but CI did not
export or import their coverage. The eight security findings treat local CLI arguments as

`NOSONAR(S8707)`, with its reason. Other rules and all other lines remain analyzed. This syntax is
documented in [Sonar's Python suppression announcement](https://community.sonarsource.com/t/python-issue-suppression-improvements-nosonar-and-new-rules/145017).
