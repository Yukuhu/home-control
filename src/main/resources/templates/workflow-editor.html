1. Workflow details
2. Fetch JSON

Fetch one JSON response from this address. Request headers apply only to this fetch.

Replacing with no rows clears all saved headers.

3. Choose tiles

Artwork must use a public HTTPS address without credentials, query parameters or fragments.

The array pointer reads the whole response. ID, title, subtitle and artwork pointers read each entry. IDs must be unique strings or whole numbers. Up to 200 entries are supported.

JSON Pointer examples: /items, /auth/token. Leave a pointer blank to select its root. Escape a slash as ~1 and a tilde as ~0. Optional selections apply only when their checkbox is selected.

4. Map fields

Give each value a name, such as A or Token. One-tile workflows read the whole response. Generated tiles can also read the current entry. New mappings start sensitive to mask previews.

Switching to one tile changes all mappings to Whole response. Review their pointers. If you switch back to generated tiles, choose Current entry again where needed.

5. Build the media address

Insert mapped fields as {A} in a path or query value, for example https://media.example/play?id={A}. Values are URL encoded for you.

Use a direct media address and matching type, such as video/mp4, audio/mpeg, or application/vnd.apple.mpegurl. Your receiver must reach it directly. Custom media-download headers are not supported.

6. Action

Play sends a Cast LOAD to the Chromecast or Cast-enabled device selected on the Dashboard. The receiver fetches the direct media address itself.

Protect your workflows

Create a Home Control password with your first saved workflow. You will use it to log in and protect saved addresses and credentials.

Saving never starts playback. A generated workflow may fetch JSON when its Dashboard row refreshes after Save; a single tile waits until Play. Saved credentials stay hidden; choose Keep to retain them.
